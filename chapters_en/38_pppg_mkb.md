# PPPD - ICD-10 and ICD-11 code 

*What is the code for PPPD in the International Classification of Diseases? Let's look at ICD-11 (AB32.0) and why there is no separate code in ICD-10.* 

## PPPD in ICD-11: code AB32.0 

In **ICD-11** (ICD-11), which WHO adopted in 2019 and which came into force in 2022, PPPD has its own code: 

> **AB32.0** - Persistent postural-perceptual dizziness (Persistent postural-perceptual dizziness) 

The code is included in the section: 
- **AB32** — Chronic vestibular syndrome (Chronic vestibular syndrome) 
- **AB3** — Diseases of vestibular function 

This means that PPPD is an **officially recognized medical diagnosis**, and not “nervous” or “you think.” 

## Why there is no code for PPPD in ICD-10 

ICD-10 was created in 1990, 27 years before the Barany Society formulated diagnostic criteria for PPPD in 2017. Therefore, **there is no separate code for PPPD in ICD-10**. 

### What codes are put in ICD-10 instead of PPPD 

In practice, doctors in Russia use the following replacement codes: 

| ICD-10 code | Diagnosis | Comment | 
|------------|---------|------------| 
| **H81.1** | Benign paroxysmal positional vertigo (BPPV) | Often put “out of habit”, although PPPV ≠ BPPV | 
| **H81.4** | Vertigo of central origin | If a neurologist suspects central vertigo | 
| **H81.9** | Vestibular function disorder, unspecified | The most common "junk" code | 
| **H82** | Vestibular syndrome in diseases classified elsewhere | Rarely used | 
| **F45.8** | Other somatoform disorders | When a psychotherapist makes a diagnosis | 
| **R42** | Dizziness and loss of stability | Symptom code, not diagnosis | 

### Problem for patients 

Due to the lack of a separate code in ICD-10: 
- Many doctors in the Russian Federation **do not know about PPPD** and put “VAD (autonomic dysfunction)”, “cervical osteochondrosis” or “dyscirculatory encephalopathy” 
- Patients receive ineffective treatment (nootropics, vascular drugs) 
- PPPD statistics in Russia are underestimated - the diagnosis “dissolves” in related codes 

## When will Russia switch to ICD-11 

Russia has officially begun the transition to ICD-11 in 2022. The Ministry of Health plans a complete transition by 2025–2027. After this, the code **AB32.0** will become the standard, and it will be easier for doctors to make the correct diagnosis. 

In the meantime, if your neurologist doesn’t know what PPPD is, print out [Barany Society diagnostic criteria](01_what_is_pppg.html) and show him the AB32.0 code in ICD-11.

## What to do if you are diagnosed with “VAD (autonomic dysfunction)” or “osteochondrosis” 

VAD (autonomic dysfunction) (vegetative-vascular dystonia) is an **outdated Soviet diagnosis**, which is not found in either ICD-10 or ICD-11. Osteochondrosis of the cervical spine occurs in 90% of people over 30 years of age and **is not the cause of chronic dizziness**.
